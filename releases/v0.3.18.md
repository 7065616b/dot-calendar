# AI 캘린더 v0.3.18 — 네이티브 명령 검색과 빠른 보기

Dot Calendar의 표시 이름이 **AI 캘린더**로 바뀝니다. 기존 실행 파일 `dot-calendar.exe`, 설치 위치, `%USERPROFILE%\.dot-calendar` 저장소, 로컬 스킬·MCP 식별자와 기존 바로가기를 유지합니다. 시작 메뉴에 새 이름의 바로가기를 추가합니다. AI 모델을 자체 내장하지 않으며, 지원 AI 도구를 연결하거나 일정 브리핑을 복사해 사용합니다.

**Ctrl+K**로 명령 검색을 열고, 위·아래 방향키로 선택해 Enter로 실행합니다. Escape로 닫으면 이전 입력 위치로 돌아갑니다. 작성 중인 메모는 검색을 여닫아도 유지되며 저장을 눌러 반영합니다. 월간·하루·완료 보기와 **컴포넌트** 화면, Primary·Secondary·Ghost 버튼, 최대 세 개의 알림을 제공합니다.

Win32/GDI를 유지하며 DirectComposition으로 유한한 이동·확대·투명도 애니메이션을 처리합니다. 애니메이션이 끝나면 임시 레이어와 타이머를 정리합니다. Windows 동작 줄이기·고대비 설정을 반영하고, DPI 변경 시 폰트와 알림 전체를 다시 그립니다. 네이티브 표준 컨트롤의 접근성 역할·선택·실행 동작을 유지합니다. 블러와 그림자는 캐시된 네이티브 근사 표현이고, 알림 스택 재배치는 즉시 적용됩니다. 별도 웹 런타임이나 Rust 의존성은 추가하지 않았습니다.

최종 배포 후보의 네이티브 검사 145개와 디버그 검사 196개, Rust 기본 기능 테스트 108개와 선택 기능 제외 테스트 105개가 통과했습니다. 실제 키보드·마우스·Windows UI Automation, 메모 저장, 초점 복귀, 반복 실행·종료를 확인했습니다. 335개 일정 사본의 세 차례 정상 실행·종료 후 JSON 바이트, 삭제 기록 13개와 시퀀스 파일, 재사용 금지 ID 11개를 보존했습니다. CLI/MCP·AI 연결·수집기 회귀 일곱 묶음도 통과했습니다.

애니메이션과 알림 정리 후 3초 유휴 관측에서 CPU 증분·읽기·쓰기 I/O는 0, GDI/User 자원은 27/41로 유지됐습니다. 해당 배포 빌드의 전용 메모리는 약 3.58MiB였습니다. 이는 영구적인 0 부하나 다른 환경의 성능 보장이 아닙니다. DPI 96/144/192와 고대비·동작 줄이기는 앱 내부 시험 경로로 검증했으며, 실제 여러 모니터 간 이동과 외부 AI 계정·Google 원격 쓰기는 검증하지 않았습니다.

Windows 10 1703 이상 / Windows 11 x64 공개 미리보기입니다. 설치 EXE, 휴대용 ZIP과 SHA-256 목록을 제공합니다. 설치기는 정상 종료에 실패하면 업데이트를 중단하며 강제 종료하지 않습니다. 배포 파일에 개인 일정·계정 정보·수집 결과·활성화 설정·안전 사본은 포함하지 않습니다. 최신 사용자 데이터 위에 과거 백업을 복원하지 마세요.
