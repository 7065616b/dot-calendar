# Dot Calendar v0.3.12 — 설치부터 닷 연결까지

**설치 파일 하나로 시작하고, 닷에게는 짧게 말하세요.**

- **Windows 설치 파일**: 압축 풀기와 PowerShell 작업 없이 현재 사용자 계정에 설치합니다. 시작 메뉴 바로가기와 닷의 로컬 연결을 함께 준비합니다. 관리자 권한은 필요하지 않습니다.
- **앱의 Dot 버튼**: 한 번 전달할 기본 캘린더 설정 문장을 복사합니다. 이후 “내일 오후 3시 회의 추가해줘”, “이거 캘린더에 반영해줘”, “오늘 일정 알려줘”처럼 요청하는 흐름입니다.
- **마감일 제안**: 닷의 작업에서 구체적인 완료 예정일이나 마감일이 나오면 한 번 추가를 제안하고, 사용자가 수락한 뒤 저장하도록 연동 지침을 개선했습니다.
- **안전한 갱신**: 실행 중인 달력의 저장·종료를 확인한 뒤 업데이트합니다. 변경된 연결 파일은 백업하며, 앱 제거 후에도 개인 일정은 남습니다.
- **저자원 방식 유지**: Rust·Win32, 상주 연결 서버나 새 유휴 폴링 없음. 실행 파일 1.01 MiB, 일정 100개에서 전용 커밋 2.60 MiB / 공유 페이지 포함 작업 집합 15.21 MiB. 3회 중앙값이며 자세한 조건은 웹의 측정 자료를 참고하세요.

## 시작하기

1. `dot-calendar-0.3.12-windows-x64-setup.exe`를 실행합니다.
2. 달력의 **Dot** 버튼에서 문장을 복사해 닷에게 한 번 보냅니다.
3. 이후 평소 말투로 일정을 조회하고 추가·수정합니다.

Windows 10 1703 이상 / Windows 11 x64용 공개 미리보기입니다. 포터블 ZIP도 함께 제공합니다. 사용자 일정은 설치 폴더와 분리된 `%LOCALAPPDATA%\DotCalendar`에 저장됩니다.

## 확인 범위

47개 Rust 테스트, 엄격 Clippy, Release 빌드, 격리 CLI/MCP 및 설치된 닷 helper 검사를 통과했습니다. 설치·재설치·제거와 실패 경로에서 데이터 보존을 확인했습니다. 다운로드 파일의 무결성은 `SHA256SUMS.txt`로 확인할 수 있습니다.

닷의 PC 연결과 온라인 ChatGPT 앱이 필요합니다. 기본 캘린더 선호는 복사한 문장을 사용자가 닷에게 전달하는 방식이며, 앱이 클라우드 기억을 직접 수정하지 않습니다. **실제 Your dot 계정에서의 짧은 요청·자동 제안, Google 실계정 및 기기 간 왕복 동기화는 별도 확인이 필요합니다.** 현재 설치 파일과 앱은 코드 서명이 없는 미리보기입니다.
