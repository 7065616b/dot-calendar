# Dot Calendar v0.3.16 — 저장 경로 보호와 반복 일정 최적화

Dot 연결과 일반 실행이 같은 `%USERPROFILE%\.dot-calendar` 저장소를 사용합니다. 기존 AppData 저장소가 남아 있으면 검토된 이전을 요구하며, 빈 달력으로 초기화하지 않습니다. 이미 열었던 일정 파일이 사라진 경우에도 새 파일로 덮어쓰지 않습니다. 창 컨트롤러가 사라지는 경우의 재실행 처리도 보강했습니다.

일정 검증과 저장 후 확인의 불필요한 정렬·문자 계산을 줄였습니다. 전체 파일 재읽기, 모든 필드의 저장 확인, 사용자 변경 충돌 검사는 유지합니다. 날짜 계산과 반복 일정 배치, 화면 문자열 처리도 개선했습니다.

동일 환경의 가상 데이터 함수 측정에서 500개 일별 반복 일정 배치는 약 46%, 긴 메모가 있는 500개 일정 검증은 약 19% 짧아졌습니다. 앱 전체 시작 속도나 메모리가 같은 비율로 개선됐다는 의미는 아닙니다.

기존 일정·완료 상태·삭제 복구 이력·재시도 ID 보존을 자동 테스트와 사본 GUI 반복 실행으로 확인했습니다. 개인 일정, 계정 정보, 수집 결과, 백업 및 QA 파일은 패키지에 포함하지 않습니다.

매일 첫 실행 공모전 수집은 아직 실험 단계이며 **이 기본 배포에서는 빌드·활성화하지 않습니다**. 별도 검증 중인 기능을 기존 자동 수집으로 안내하지 않습니다.

Windows 10 1703 이상 / Windows 11 x64 공개 미리보기입니다. 설치 EXE, 휴대용 ZIP과 SHA-256 목록을 제공합니다. 과거 일정 백업을 최신 저장소 위에 복원하지 마세요. 기존 AppData 저장소에 대한 이전 안내가 나오면 해당 저장소를 보존한 상태에서 경로를 확인하세요.
