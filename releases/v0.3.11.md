# Dot Calendar v0.3.11 · Public preview

Windows 바탕화면에 붙여 두는 가벼운 달력과 메모 위젯입니다. Rust 소스를 MIT 라이선스로 공개합니다.

## 핵심 기능

- 일정별 블록, 날짜 칸에서 직접 메모 작성·수정, 전체 메모 열람
- `+N`과 **하루 일정**으로 모든 일정을 스크롤 확인. 기존 100개 메뉴 제한 제거
- 닷에서 일정을 읽고 추가·변경할 수 있는 로컬 스킬과 stdio MCP
- 열린 하루 목록도 데이터 변경 신호에 따라 갱신하고 선택한 일정 유지
- 음력·한국 공휴일, 반복 일정, 투명도·테마, 백업·복원
- 선택적 Google Calendar 연결과 가져온 일정 표시/숨김

## 다운로드와 실행

`dot-calendar-0.3.11-windows-x64-preview.zip` 전체를 압축 해제하고 `dot-calendar.exe`를 실행하세요. Windows 10 1703 이상 / Windows 11 x64용입니다. ZIP에는 닷 연결 스킬과 의존성 라이선스가 포함됩니다.

닷 연결은 압축을 푼 폴더의 `scripts/install-dot-skill.ps1`을 실행하고, 닷에 이 PC의 `dot-calendar` 스킬로 오늘 일정을 조회하도록 요청합니다. PC와 대화 앱의 연결 및 온라인 상태가 필요합니다.

## 검증과 현재 범위

45개 Rust 테스트, 엄격 Clippy, CLI/MCP·동시 쓰기 검사와 Windows UI의 101번째 일정 표시·실시간 목록 갱신을 확인했습니다. 개인 일정이나 계정 정보는 배포물에 포함되지 않습니다.

이 빌드는 서명되지 않은 공개 미리보기입니다. 별도 설치기·자동 업데이트는 제공하지 않습니다. Your dot 실계정 대화와 Google OAuth·두 기기 왕복은 아직 검증하지 않았습니다. Google 연결에는 본인의 Desktop OAuth 클라이언트 설정이 필요합니다. 중요한 일정은 백업을 권장합니다.

한국 공휴일은 현재 코드의 2024–2050년 규칙 기반이며, 향후 임시공휴일·선거일·법령 변경은 자동 반영되지 않습니다. 반복 일정의 수정과 삭제는 시리즈 전체에 적용됩니다.
