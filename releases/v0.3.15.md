# Dot Calendar v0.3.15 — 다시 열 때 일정 갱신

달력을 숨겼다가 다시 열 때 저장된 일정을 다시 읽고 화면을 갱신합니다. 외부 저장의 변경 알림이 전달되지 않아도 빈 캐시나 오래된 일정 목록이 화면에 남지 않도록 수정했습니다. 저장 형식과 기존 일정·설정은 유지됩니다.

일정 저장과 종료·재실행에 대한 회귀 검증을 추가했습니다.

- 89개 가상 일정으로 일반 창과 바탕화면 모드에서 각각 3회 재시작, 외부 저장, 숨기기·다시 열기를 검증했습니다. 빈 캐시에 일정이 추가되고 변경 알림이 누락된 경우에도 다시 열면 정상 표시됩니다.
- 반복 저장·재실행 후 일정과 완료 상태 유지, 원자적 저장 실패 시 원본 보존, 외부 변경 보존과 충돌 검사를 Rust 테스트로 확인했습니다.
- Rust 테스트 58개, Clippy 경고 없음, 격리된 CLI·MCP·닷 연결 및 호출 도우미 검사를 통과했습니다.

기존 설치 파일을 다시 실행하면 업데이트됩니다. 일정과 설정은 설치 폴더와 별도로 보관됩니다. Windows 10 1703 이상 / Windows 11 x64용 공개 미리보기이며 설치 파일, 휴대용 ZIP, `SHA256SUMS.txt`를 제공합니다. 웹사이트 성능 수치는 기존 v0.3.12 측정 결과입니다.
