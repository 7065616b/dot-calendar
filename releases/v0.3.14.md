# Dot Calendar v0.3.14 — 빠른 삭제와 되돌리기

닷에게 날짜와 정확한 제목을 알려 일정을 삭제할 때, 이제 로컬 도구 한 번의 호출에서 대상을 찾고 삭제 결과까지 확인합니다. 같은 날짜·제목의 일정이 여럿이면 임의로 지우지 않고 시각이나 일정 ID를 확인하도록 합니다. 반복 일정은 시리즈 전체 삭제를 명시해야 합니다.

- 삭제한 로컬 일정의 원본을 데이터 폴더의 `deleted/`에 보관합니다. 앱의 ··· 메뉴에서 **마지막 삭제 되돌리기**를 사용할 수 있습니다.
- 닷 연결에는 `calendar_deleted`와 `calendar_restore`가 추가되어 로컬 도구가 총 9개입니다. 특정 삭제 일정을 ID로 복구할 수 있고, ID를 생략하면 가장 최근 삭제를 되돌립니다.
- 메모·하루 일정 창이 열린 동안 외부에서 일정이 변경되어도 저장소 변경 신호를 처리하도록 수정했습니다.

이번 변경은 **로컬 도구 호출 왕복 수를 줄입니다**. 닷의 대화 처리, PC 연결 및 클라우드 동기화까지 포함한 전체 소요 시간을 일정하게 보장하지는 않습니다. Google에 이미 반영된 삭제는 로컬 복구만으로 원격 복구를 보장하지 않습니다. JSON 내보내기는 활성 달력 데이터만 포함하며 별도의 `deleted/` 보관함은 포함하지 않습니다.

기존 설치 파일을 다시 실행하면 업데이트됩니다. 일정과 설정은 설치 폴더와 별도로 보존됩니다. Windows 10 1703 이상 / Windows 11 x64용 공개 미리보기이며 설치 파일, 휴대용 ZIP, `SHA256SUMS.txt`를 제공합니다. 웹의 성능 수치는 표시된 v0.3.12 측정 결과입니다.

Rust 테스트 55개, Clippy 경고 없음, 격리된 CLI·MCP·닷 연결 검사를 통과했습니다. 삭제·복구 검사는 중복 제목, 시각 구분, 반복 시리즈 보호, 동시 편집 충돌, 재실행 후 복구와 원본 보존을 포함합니다. 실제 Your dot 대화를 통한 변경 후 전체 지연 시간과 화면 갱신은 사용자 환경에서 추가 확인이 필요합니다.
