# Dot Calendar icon

The icon combines the yellow Your dot character, round glasses and bow tie with a calendar sheet. Its rounded shape, restrained depth and simple centered composition were informed by [Apple's app icon guidance](https://developer.apple.com/design/human-interface-guidelines/app-icons) and [Icon Composer](https://developer.apple.com/icon-composer/). Character reference: [OpenAI's Introducing dots](https://openai.com/index/introducing-dots/).

This independent project is not an official OpenAI or Apple product. The referenced character and brands belong to their respective owners.

`app-icon.png` is the generated master. `app.ico` contains 16, 20, 24, 32, 40, 48, 64, 128 and 256 pixel versions. `web/app-icon.png` is a 128 pixel export. The app embeds the ICO and uses a shared Windows icon handle; it does not decode the master image or run an animation.

Created with the built-in image generation tool. Export sizes are produced with Lanczos resampling; the generated alpha is preserved.
