GOOD TO KNOW

자주 묻는 내용

일정 데이터는 어디에 저장되나요?

개인 일정과 설정은 실행 파일과 분리된 이 PC의 %LOCALAPPDATA%\DotCalendar에 저장됩니다. 앱에는 백업·복원 기능이 있습니다.

Google Calendar 연결은 필수인가요?

아닙니다. 로컬 달력은 Google 연결 없이 사용할 수 있습니다. Google 연동을 선택하면 설정에서 본인의 데스크톱 앱용 OAuth 클라이언트 ID를 직접 입력합니다. 실제 계정 로그인과 여러 PC 왕복 동기화는 현재 미리보기 검증 범위 밖입니다.

새 버전으로 바꾸면 기존 일정은 어떻게 되나요?

실행 파일과 개인 데이터의 위치가 분리되어 있습니다. 새 압축을 푼 뒤 새 실행 파일을 사용해도 기존 PC의 일정 파일을 그대로 읽도록 설계되었습니다. 업데이트 전에는 앱의 백업 기능으로 복사본을 남겨 두세요.

Windows가 다운로드 또는 실행 경고를 보여요.

현재 공개 서명이 적용되지 않은 미리보기 빌드입니다. 파일 출처와 GitHub 릴리스의 정보를 확인하고 실행 여부를 결정하세요.
